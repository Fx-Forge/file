GIT BASH COMMANDS — VCG PRACTICAL CHEAT SHEET

BASIC FLOW 1: SSH AND GITHUB AUTHENTICATION
ssh-keygen -t ed25519 -C "you@example.com"
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
cat ~/.ssh/id_ed25519.pub
ssh -T git@github.com

BASIC FLOW 2: GIT CONFIGURATION
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global core.editor "code --wait"
git config --list

BASIC FLOW 3: INITIALIZE REPOSITORY AND PUSH FIRST FILE
git init
git remote add origin <url>
echo "Hello" > file.txt
git status
git add file.txt
git status
git commit -m "Message"
git push -u origin main

BASIC FLOW 4: ADD AND PUSH A SECOND FILE
echo "Hello" > file2.txt
git status
git add file2.txt
git status
git commit -m "Message"
git push

BASIC FLOW 5: CREATE A BRANCH, PUSH IT, AND PRACTISE MERGE/REBASE
git checkout -b branch_name
echo "Hello" > file3.txt
git status
git add file3.txt
git status
git commit -m "Message"
git push origin branch_name

git checkout main

git merge branch_name
git rebase main

NOTE: After checking out main, `git merge branch_name` merges the branch into main.
To practise rebasing the feature branch onto main, switch back to the feature branch first:
git checkout branch_name
git rebase main

============================================================

NOTE: The first push assumes your local branch is named main and the remote URL is correct.
If the remote repository already contains commits (for example, a README created on GitHub),
you may need to pull and reconcile those changes before pushing.
